# poultry_Growth_Project
Poultry Growth Analysis: Kuroiler vs Sasso

Overview

An exploratory data analysis of 260 Kuroiler and Sasso chickens, examining body-weight trends and growth performance over 72 weeks.

Tools

- Microsoft Excel
- Python (Pandas, NumPy, Matplotlib, SciPy)
- Tableau

Key Findings

- Analysed body-weight trends across the two strains.
- Compared average weight gain among birds with complete Week 0 and Week 72 records.
- Sasso recorded a higher average weight gain (2,998.13 g) than Kuroiler (2,740.05 g).
- Identified substantial missing data and limitations affecting the comparison.

Limitations

Only 101 birds had records at both Week 0 and Week 72. The strains were also raised in different pens, making it difficult to separate strain effects from pen effects.

Deliverables

- Excel analysis and visualisations
- Python analysis notebook
- Tableau dashboard
